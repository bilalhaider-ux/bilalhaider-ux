### 🔬 Engineering & Research Focus

- **Statistical Foundations & Modeling:** Rigorous exploratory data audit, outlier isolation, hypothesis testing, and probabilistic distributions rooted in academic statistics.
- **Predictive ML Pipelines:** Tabular architectures using Scikit-Learn, LightGBM, and CatBoost with strict Out-of-Time (OOT) validation and cost-matrix threshold tuning.
- **Generative AI & LLM Systems:** Document intelligence, multimodal reasoning via Google Gemini 2.5, agentic workflows, and semantic retrieval systems.
- **Full-Stack Prototyping:** Reactive interfaces with Next.js, React, and Tailwind CSS backed by scalable endpoints with Django, FastAPI, and PostgreSQL.
